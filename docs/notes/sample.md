# 샘플 노트

문서 상단의 frontmatter는 페이지 메타데이터로 사용됩니다. 본문에서는 다루지 않는 정보(작성일, 태그 등)를 보관할 수 있습니다.

## 개요

이 노트는 단순히 **렌더링 확인용**입니다. 실제 사용 시에는 이런 식으로 자유롭게 작성하시면 됩니다.

## 결정 사항

1. **뷰어**: VitePress 채택 — Vite 빠르고, 한글 렌더링 안정적
2. **폰트**: Inter (영문) + Pretendard Variable (한글)
3. **패키징**: degit 템플릿 (`npx degit ilwonyoon/markdown-preview`)
4. **모바일**: 같은 Wi-Fi 로컬 IP, 포트 5173 고정

- [VitePress 공식 문서](https://vitepress.dev)
